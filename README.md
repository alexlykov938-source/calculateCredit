# Credit Calculate CLI

Простой интерактивный консольный кредитный калькулятор на Go для расчета реального банковского аннуитетного кредита с разбивкой переплаты по годам. Проект создается в рамках обучения и развития структурного мышления.

## Текущая версия: v0.0.2 (In Development)

### Что уже реализовано:
* **Пакетная структура:** Бизнес-логика полностью вынесена из `main.go` в изолированный внутренний пакет `internal/calculate`.
* **Математика аннуитета:** Корректный расчет ежемесячного платежа и уменьшения остатка основного долга с использованием пакета `math`.
* **Годовая аналитика:** Логика симуляции кредита месяц за месяцем с точной фиксацией переплаты за каждый конкретный год.
* **Интерактивный CLI:** Ввод данных пользователем (сумма, ставка, срок) прямо через консоль во время работы программы с базовой валидацией.

## Как запустить проект локально

1. Убедитесь, что у вас установлен Go (версии 1.11 и выше, так как используются Go Modules).
2. Склонируйте репозиторий или откройте папку с проектом в терминале.
3. Инициализируйте модули (если запускаете впервые):
   ```bash
   go mod init creditCalculate
   ```
4. Запустите программу одной командой:
   ```bash
   go run main.go
   ```

## Готовые сборки (Бинарники)

Если вы не хотите устанавливать Go и компилировать проект самостоятельно, вы можете скачать уже готовые исполняемые файлы для Windows из корня репозитория:
* `credit_bot_32.exe` — для старых 32-битных систем (например, Windows 7 32-bit).
* `credit_bot_win64.exe` — для современных 64-битных систем (Windows 10/11 64-bit).

Просто скачайте нужный файл, откройте терминал/командную строку в папке с файлом и запустите его.
