# Credit Calculate CLI

Простой интерактивный консольный кредитный калькулятор на Go для расчета реального банковского аннуитетного кредита с возможностью выбора краткого (по годам) или детального (по месяцам) отчетов. Проект создан в рамках обучения, развития структурного мышления и отработки принципов чистой архитектуры.

## Текущая версия: v1.0.0 (Official Release)

### Что реализовано в релизе:
* **Принцип DRY и пакетная структура:** Вся бизнес-логика и математические расчеты инкапсулированы в едином скрытом симуляционном движке внутри пакета `internal/calculate`. Публичные функции работают как чистые фильтры данных.
* **Математика аннуитета:** Корректный расчет ежемесячного фиксированного платежа и динамического уменьшения остатка основного долга с автоматическим устранением погрешностей округления (`-0.00`).
* **Гибкая аналитика (Два режима):** 
  * Краткий отчет — агрегированные показатели переплаты и остатка долга строго по годам.
  * Детальный отчет — подробная разбивка платежа на проценты и тело долга на каждый месяц.
* **Псевдографические таблицы:** Вывод результатов структурирован в аккуратные текстовые таблицы фиксированной ширины для удобного визуального восприятия.
* **Интерактивный CLI-цикл:** Программа работает в бесконечном цикле, защищена от невалидного ввода пользователя (команда `continue`) и предоставляет удобное текстовое меню для выбора отчетов и комфортного перезапуска или выхода (команда `break`).

## Готовые сборки (Бинарники)

Вы можете скачать уже скомпилированные исполняемые файлы для Windows прямо из корня репозитория (установка Go не требуется):
* `credit_bot_32.exe` — для старых 32-битных систем (например, Windows 7 32-bit).
* `credit_bot_win64.exe` — для современных 64-битных систем (Windows 10/11 64-bit).

*Примечание:* Программа спроектирована так, что окно консоли не захлопнется автоматически после выполнения расчетов — добавлено ожидание нажатия клавиши Enter для выхода.

## Как запустить исходный код локально

1. Убедитесь, что у вас установлен Go (версии 1.11 и выше).
2. Склонируйте репозиторий и откройте папку с проектом в терминале.
3. Запустите программу одной командой:
   ```bash
   go run main.go
   ```
